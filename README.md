# Arquitetura Modular de Jogos em Godot Engine

Projeto prático desenvolvido como Trabalho de Conclusão de Curso (TCC) para o curso de [Nome do seu Curso] na Universidade do Contestado (UnC).

## Sobre o Projeto
Este repositório contém a implementação da arquitetura modular para jogos do gênero survivor/bullet heaven desenvolvida em GDScript na Godot Engine.

## Como Executar
1. Baixe o projeto e abra na Godot Engine (versão 4.x).
2. Execute a cena principal `res://Main.tscn`.
